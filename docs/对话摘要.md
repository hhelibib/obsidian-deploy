# 对话摘要

这是 2026-10-06 这次对话定下来的做法，方便以后接着做，不用翻聊天记录。

## 目标

在一台 **2 核 2G** 的阿里云服务器上，自建一个必须登录才能看的 Obsidian 文档站。编辑用 Obsidian 写，读者在网页上看和评论。

服务器系统：**Alibaba Cloud Linux 3.2104 U11 (OpenAnolis Edition)**。域名和公网 IP 已经指向这台机器。

## 定下来的要求

1. 站点必须登录才能看。
2. 系统是阿里云 Linux 3，用 `dnf`，不用 Ubuntu 那套 `apt`。
3. 域名和公网 IP 已经就绪。
4. 笔记里会有不能公开的内容。
5. 多个人可以改同一个库。
6. 评论不能要求读者拥有 GitHub 账号。

## 采用的做法

| 事项 | 决定 |
| --- | --- |
| 写作 | 编辑自己的电脑上用 Obsidian |
| 笔记存放 | 服务器上的私有 Git 仓库 `/home/garden/vault.git`，不把笔记推到 GitHub |
| 网站生成 | Quartz。保留双链、搜索、标签、图谱 |
| 登录 | Nginx 为每个人单独建用户名和密码，浏览器弹出登录框 |
| 不进网站的笔记 | 放进 `private/`，或在文首写 `draft: true` |
| 评论 | Artalk + SQLite，只监听本机 `127.0.0.1:23366`。读者填昵称 |
| 多人修改 | 每人一把 SSH 密钥，用 Obsidian Git 插件推送。同时改同一篇会冲突，需要先拉取再解决 |
| 内存 | 先加 2GB 交换分区。构建时 Node 堆内存限制在 768MB |
| 安装文件 | 放在 GitHub 上的这个仓库。服务器 `git clone` / `git pull` 获取 `deploy/` |

不在这台机器上跑的东西：CouchDB 同步、思源、数据库型维基、一整套独立登录中心。

## 两种权限

- **网站账号**：只能看已发布页面和评论。命令是 `add-reader.sh`。
- **Git 密钥**：才能改笔记，并且在 Obsidian 里看得到 `private/`。命令是 `add-editor.sh`。

编辑之间不能互相隐藏笔记。收回密钥也删不掉对方电脑上已经克隆的副本。

## 仓库里有什么

这个 GitHub 仓库只放安装程序和说明：

- `README.md`：在服务器上怎么拉取、安装、加人
- `deploy/`：安装脚本、Nginx 和评论配置、示例笔记
- `docs/对话摘要.md`：本文件

笔记正文、网站密码、SSH 私钥不要提交到这个仓库。

## 服务器装好后的路径

| 路径 | 内容 |
| --- | --- |
| `/root/garden-deploy` | 从 GitHub 拉下来的本仓库 |
| `/home/garden/vault.git` | 笔记库 |
| `/opt/quartz` | 网站构建程序 |
| `/var/www/garden` | 已经发布的网页 |
| `/var/lib/artalk` | 评论数据 |
| `/root/garden-passwords.txt` | 安装时生成的两套初始密码 |

## 还没在你的服务器上执行

脚本写好了，并用示例笔记做过一次本地构建：`private/` 和 `draft: true` 的笔记没有出现在生成的网页里。安装、申请证书、接入你的域名，需要你在阿里云服务器上按 `README.md` 执行。
